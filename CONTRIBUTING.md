# Contributing

## Disputes

If you think a score is wrong, open a score dispute. Name the case, the run, and the door or window, and say what is wrong. We read every dispute. When the reviewer was wrong, we use the case to improve it.

## New cases and criteria

Propose a case or a criterion with an issue. For a criterion, say what an architect checks, why it matters, and how you can tell from a model that it passes.

## License of contributions

By contributing a case, a criterion or a review, you agree that it is published under the same license as the rest of the repository, [CC BY-NC 4.0](LICENSE).

## How the benchmark changes

- A case ID never changes. A changed building gets a new case ID.
- The meaning of a criterion never changes. A changed rule gets a new ID.
- A new case or criterion makes a new version of the part. Results are only compared on the same version.
- A results folder is not edited after release. A new run gets a new folder.
